# Cross-World Civilization Architecture — Draft 1

## Purpose

Universal Simulation Sandbox must support cultivation, technological and hybrid civilizations through the same causal simulation core. Civilization style is derived from knowledge, capability, institutions and resources rather than a single permanent genre label.

## Civilization State

```text
Civilization
├─ Primary Path: Emergent / Cultivation / Technology / Hybrid
├─ Historical Stage and Level
├─ Knowledge Graph with provenance
├─ Capability Vector
├─ Institutions and factions
├─ Cross-World Connections
└─ Innovations
```

The initial PoC capability vector contains Energy, Production, Medicine, Computation, Communication, Spaceflight, WorldTravel, Cultivation, LawManipulation and SoulTechnology. It can expand without changing the event model.

## Independent Evolution Paths

A tribal civilization may discover cultivation or repeatable scientific inquiry. Cultivation worlds develop sects, formations, medicine, artifact crafting, soul knowledge and law manipulation. Technology worlds develop experimental science, precision production, energy systems, computation, automation, biotechnology, communication and spaceflight.

Neither path is universally superior. Each creates a different possibility space, bottlenecks and externalities.

## Cross-World Contact State Machine

```text
Travel Capability + Detection + Motivation
→ Detected
→ First Contact
→ Knowledge Exchange
→ Integrated
```

Contact can be triggered by radio/quantum observation, foreign law resonance, a realm gate, void-capable cultivator or world-travel technology. Every connection records its two worlds, trigger, travel method, distance, trust, stage and exchange count.

## Knowledge Provenance

Transferred knowledge records the source World and acquisition method. A receiving civilization must translate and reproduce it locally; transfer raises capability less than an indigenous discovery and does not bypass material or law prerequisites.

```text
Source knowledge
→ communication and translation
→ local reproduction
→ capability gain
→ possible derived innovation
```

## Hybrid Innovation

Innovation recipes require complementary knowledge domains present across connected worlds. Implemented examples:

- Computation + Formation → Programmable Formation Network
- Energy + Formation → Planetary Qi Power Grid
- Automation + Medicine → Automated Pill Foundry
- Biotechnology + Medicine → Artificial Meridian Scanner
- Spaceflight + Formation → Resonant World Gate
- Computation + Samsara → Soul–Machine Consciousness Bridge

Innovation changes real civilization capability, development, path and connection state. It also emits a cosmic causal event that identifies both knowledge inputs, the partner world and intended purpose.

## Causal Example

```text
Technology World develops orbital observation
→ detects foreign law resonance
→ launches fold-drive research vessel
→ establishes first contact with Cultivation World
→ trust permits knowledge exchange
→ Digital Computation and Formation Geometry become jointly available
→ joint institutes create Programmable Formation Network
→ Communication and WorldTravel capability rise
→ civilization becomes Hybrid
→ new economic, military and World Will consequences become possible
```

## Current PoC Scope

Implemented:

- technology as an independent post-tribal path
- multi-dimensional civilization capability
- technology and cultivation knowledge pools
- distance-aware cross-world detection and travel methods
- staged first contact
- knowledge transfer with provenance
- hybrid innovation recipes
- causal historical events
- World Detail panels for capability, connections and innovations

Future extensions:

- institutions, research projects and prototype failures
- compatibility and prerequisite graphs instead of domain-only recipes
- trade, migration, disease and ecological contamination
- espionage, embargoes, colonization and cross-world war
- World Will reaction to foreign knowledge and authority
- AI-driven civilization goals and candidate actions
