# World Will Architecture — Draft 1

เอกสารนี้ต่อยอด Universal Simulation Theory และ AI Agent Decision Architecture เพื่อกำหนดว่า World Will / Heavenly Dao ควรถูกขับเคลื่อนอย่างไร โดยไม่เป็นเพียง random event generator และไม่มอบอำนาจแก้ reality ให้ AI โดยตรง

## 1. ข้อสรุป

World Will ควรเป็น Hybrid Hierarchical Controller ที่ประกอบด้วยสามบทบาท:

```text
World Law      = กฎที่โลกต้องบังคับเสมอ
World Organism = ระบบตรวจภัย รักษาสมดุล และเอาตัวรอด
World Agent    = ตัวตนที่มีบุคลิก เป้าหมาย และเลือกยุทธศาสตร์
```

```text
World Laws
→ World State Monitor
→ Pressure / Threat Assessment
→ World Goals
→ Intervention Policy
→ Candidate Interventions
→ Budget & Law Validation
→ Action Resolution
→ Consequences / Event Graph / New State
```

AI ใช้ได้เฉพาะการเลือกยุทธศาสตร์และ intervention ภายในขอบเขตที่ World Law อนุญาต ส่วน Simulation Engine เป็นผู้ตรวจค่าใช้จ่ายและตัดสินผลจริง

## 2. World Law Kernel

ส่วนนี้เป็น deterministic rules หรือ invariant ที่ AI ไม่มีสิทธิ์เปลี่ยนโดยตรง:

- เพดานระดับการบำเพ็ญของ World
- การอนุรักษ์พลังงาน สสาร วิญญาณ และทรัพยากร
- Samsara และการหมุนเวียนวิญญาณ
- ความเสถียรของมิติและ World Boundary
- เงื่อนไขพื้นฐานของ Heavenly Tribulation
- prerequisites ของ World Ascension
- กฎกรรมและ causal accounting
- ขอบเขตอำนาจของ World Will
- ต้นทุนขั้นต่ำของ intervention

ตัวอย่างเช่น Cultivator ที่พยายามทะลวงเกิน cultivation ceiling จะถูก World Law ปฏิเสธหรือกดทับโดยอัตโนมัติ ไม่จำเป็นต้องให้ AI ตัดสินทุกครั้ง

## 3. World Homeostasis

World Will ต้องตรวจ derived state เพื่อรักษาสมดุลเสมือนระบบภูมิคุ้มกัน:

```text
World Integrity
Law Cohesion
World Origin Reserve
Qi Balance
Ecological Stability
Population Stability
Samsara Capacity / Congestion
Karmic Imbalance
Civilization Pressure
Foreign Authority Threat
Ascension Readiness
```

Threat และ pressure ต้องมาจาก state จริงและ causal history ไม่ใช่ตัวเลขสุ่มลอย ๆ ตัวอย่าง threat score:

```text
Threat =
    BoundaryDamage
  + LawCorruption
  + OriginEnergyDrain
  + SamsaraCollapse
  + ForeignAuthority
  + CivilizationDestruction
```

ระดับการตอบสนองเบื้องต้น:

| Pressure | การตอบสนอง |
|---|---|
| ต่ำ | สังเกต ส่งลาง หรือปรับ probability เล็กน้อย |
| กลาง | สนับสนุนผู้ต่อต้าน เปิดโอกาส หรือเพิ่ม tribulation pressure |
| สูง | Heavenly Tribulation, suppression หรือปลุก guardian |
| วิกฤต | ขับไล่ foreign entity, ปิดผนึกภูมิภาค หรือ emergency repair |
| ใกล้ล่มสลาย | sacrifice origin, evacuate souls หรือ world survival protocol |

## 4. Personalized World Will Profile

World แต่ละแห่งใช้ shared strategic policy ได้ แต่มี profile เฉพาะโลก:

```text
WorldWillProfile
- Primary Laws
- Temperament
- Self-Preservation
- Growth Desire
- Intervention Tendency
- Mercy / Ruthlessness
- Order / Freedom Preference
- Native-Life Priority
- Civilization Preference
- Cultivation Preference
- Foreign-Entity Tolerance
- Long-Term Agenda
```

ตัวอย่าง:

- `Azure Mercy` ให้ความสำคัญกับชีวิตและ Samsara สนับสนุนผู้มีกรรมดี และใช้ tribulation เพื่อทดสอบจิตใจ
- `Iron Heaven` ให้ความสำคัญกับการแข่งขัน สนับสนุนผู้แข็งแกร่ง ยอมรับ casualty สูง และใช้ tribulation รุนแรง

ทั้งสองโลกยังอยู่ใต้ universal laws เดียวกัน แต่เลือกวิธีตอบสนองต่างกัน

## 5. Candidate Interventions

World Will ไม่ควรสั่งผลลัพธ์ว่าใครต้องชนะ แต่เลือก intervention ที่เป็นไปได้:

```text
Observe
Send Omen
Reveal Information
Alter Luck Slightly
Expose Hidden Ruin
Guide a Mentor
Create Resource Opportunity
Favor / Withdraw Favor
Strengthen Tribulation
Suppress Foreign Cultivator
Awaken World Guardian
Repair Spiritual Vein
Accelerate Samsara
Seal a Region
Raise World Boundary
Attempt World Ascension
```

Simulation Engine ตรวจ prerequisite, authority, budget และ resistance ก่อน resolve ผล ตัวละครยังมีสิทธิ์ไม่ตอบรับ ล้มเหลว ตีความลางผิด หรือใช้โอกาสไปในทิศทางที่ World Will ไม่คาดคิด

## 6. Heaven-Favored Person

Heaven-favored person คือ candidate ที่มีประโยชน์เชิงยุทธศาสตร์ต่อเป้าหมายของ World ไม่จำเป็นต้องเป็นคนดีหรือเป็นผู้ชนะที่ถูกกำหนดไว้

```text
HeavenFavorScore =
    WorldGoalAlignment
  + Potential
  + KarmicContribution
  + ThreatResolutionAbility
  + LawCompatibility
  + CivilizationInfluence
  - CorruptionRisk
  - ForeignAllegiance
  - WorldDamageCaused
```

Favor ต้องขยาย possibility space ไม่ใช่บังคับ outcome เช่น:

- พบโอกาสหรือมรดกง่ายขึ้น
- ได้รับลางเตือนหรือข้อมูลก่อนผู้อื่น
- พบ mentor, ally หรือ Artifact ที่เข้ากันได้
- รอดจากเหตุร้ายโดยยังต้องจ่ายราคา
- Tribulation มีช่องทางรอด แต่ยังล้มเหลวได้
- ได้โอกาสแก้ world-level threat

World Will สามารถเลือกหลาย candidate, เปลี่ยนผู้ได้รับ favor, เลือกผิด หรือถูกผู้ได้รับ favor ทรยศได้ ตัวละครอาจเติบโตจนกลายเป็นภัยต่อ World เอง

## 7. Intervention Budget

World Will ห้ามแทรกแซงฟรี ต้องใช้ทรัพยากรจริง:

```text
World Origin
Karmic Authority
Faith / Collective Belief
Law Control
Qi Reserve
Samsara Capacity
Causal Influence
```

ตัวอย่างต้นทุนสัมพัทธ์:

| Intervention | ต้นทุน |
|---|---|
| ส่ง omen | ต่ำ |
| ปรับโชคเล็กน้อย | ต่ำ–กลาง |
| เปิด hidden opportunity | กลาง |
| Heavenly Tribulation | กลาง–สูง |
| ซ่อม Spiritual Vein | สูง |
| ต่อต้าน Immortal ต่างโลก | สูงมาก |
| World Ascension | ทรัพยากรสะสมมหาศาลและต้องผ่าน prerequisites |

การใช้ budget มากเกินไปทำให้ Origin ลดลง, World Boundary อ่อนแอ, Qi density ตก, Samsara ช้าลง และ foreign entities ตรวจพบโลกง่ายขึ้น จึงเกิด trade-off ที่มีความหมาย

## 8. Three-Layer Runtime

| ชั้น | กลไก |
|---|---|
| World Law Kernel | deterministic rules และ invariants |
| Stability Controller | threshold, state machine, PID-like regulation และ utility scoring |
| Strategic World Will | shared policy + personalized World profile + bounded planning |

Neural Network สามารถเข้ามาใน strategic layer ภายหลังเพื่อ score interventions หรือประเมินผลระยะยาว แต่ไม่มีสิทธิ์ข้าม Law Kernel ส่วน LLM ไม่จำเป็นใน runtime loop

## 9. World Impact Vector

ทุก action สำคัญควรสร้างผลกระทบมาตรฐานเพื่อให้ World Will ประเมินเหตุการณ์จากผลจริง:

```text
WorldImpactVector
- population
- ecological_stability
- qi_balance
- spiritual_veins
- samsara_load
- karmic_balance
- law_cohesion
- boundary_integrity
- civilization_knowledge
- faction_balance
- origin_reserve
- ascension_pressure
- foreign_threat
```

ผลกระทบสะสมทำให้ World Will ตอบสนองอย่างต่อเนื่อง ไม่ต้องรอ hard-coded story event

## 10. Causal Example

```text
Demonic sect drains World Origin
→ OriginDrain and BoundaryThreat rise
→ World Will generates candidates:
   - direct tribulation
   - favor an opposing cultivator
   - expose an ancient ruin
   - awaken a guardian
→ evaluates effectiveness, cost and collateral damage
→ chooses to expose a ruin to a Heaven-Favored candidate
→ candidate receives incomplete omen
→ candidate may investigate, ignore or misunderstand it
→ Simulation Engine resolves exploration and conflict
→ outcome changes sect balance and World state
→ World Will updates belief and policy
```

World Will จึงมีอิทธิพลต่อโอกาสและแรงผลักดัน แต่ไม่ได้เขียนผลลัพธ์สำเร็จไว้ล่วงหน้า

## 12. Roadmap สำหรับ PoC

1. เพิ่ม `WorldMetrics` และ `WorldImpactVector`
2. เพิ่ม `WorldWillProfile` ที่สร้างจาก world seed
3. เพิ่ม pressure/threat evaluator แบบ deterministic
4. เพิ่ม intervention budget และ regeneration rules
5. เพิ่ม rule-generated candidate interventions
6. ใช้ explainable Utility AI เลือก intervention
7. เชื่อม Heaven Favor กับ opportunity แทน guaranteed success
8. บันทึก World Will decision และ causal links
9. เพิ่ม dashboard สำหรับ pressure, budget, favored candidates และ decision audit
10. เก็บ replay data ก่อนทดลอง small learned policy

## 13. หลักการสุดท้าย

```text
Laws define what must happen.
Homeostasis detects what threatens the world.
World Will chooses what it is willing to do.
Budget determines what it can afford.
Agents and simulation resolution determine what actually happens.
```

World Will จึงไม่ใช่ผู้เขียนบทที่บังคับประวัติศาสตร์ แต่เป็นผู้มีส่วนได้เสียระดับโลกที่รับรู้ไม่สมบูรณ์ มีทรัพยากรจำกัด และพยายามผลักอนาคตไปสู่สภาวะที่ตนต้องการ
